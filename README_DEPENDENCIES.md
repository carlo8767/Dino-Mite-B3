# How to install poetry
# MAC 
Install trough pipx : command pipx install poetry
# WINDOWS
Install trough pip; command  pip install poetry
# LINUX

# How to init poetry
poetry init

# How to install dependencies
poetry install --no-root


# How to add dependencies
$ poetry add name_dependencies

# How to update 
poetry update
